# 内网部署文档（多模块）

本文档说明生产环境无法访问公网时，如何使用预先构建好的 jar 与基础镜像，在内网按模块构建应用镜像并启动服务。

本项目包含两个可独立部署的服务：`service-admin`（管理后台）、`service-client`（C 端）。内网部署只依赖本目录文件、上传的 jar 和已加载的基础镜像，不依赖仓库源码。

## 目录结构

```text
deploy/
├── Dockerfile
├── docker-compose.yml
├── deploy.env
├── start.sh
├── rollback.sh
├── service-admin-1.0.0-SNAPSHOT.jar   # 在联网环境构建后上传
└── service-client-1.0.0-SNAPSHOT.jar
```

## 前置条件

- 服务器已安装 Docker、Docker Compose Plugin。
- 已通过 `docker load -i` 加载运行时基础镜像 `eclipse-temurin:21-jre`（见 `document/deploy/docker/images`）。
- 已在可联网环境构建好各模块 jar 并上传到本目录：

```bash
# 在可联网的构建机执行
mvn -pl service-admin -am clean package -DskipTests
mvn -pl service-client -am clean package -DskipTests
# 产物分别位于 service-admin/target/*.jar、service-client/target/*.jar
```

## 部署配置

`start.sh` 和 `rollback.sh` 默认读取同目录下的 `deploy.env`。

| 配置 | 默认值 | 说明 |
|------|--------|------|
| `ENV` | `prod` | Spring Profile 和镜像 tag 环境前缀 |
| `SERVICE_CLIENT_PORT` | `18881` | service-client 宿主机端口 |
| `SERVICE_ADMIN_PORT` | `18882` | service-admin 宿主机端口 |
| `APP_LOG_DIR` | `../logs` | 日志根目录，脚本按模块追加子目录 |
| `APP_MEMORY_LIMIT` | `1G` | 容器内存上限 |
| `APP_MEMORY_RESERVATION` | `512M` | 容器内存预留 |
| `IMAGE_KEEP_COUNT` | `3` | 每个模块保留的历史镜像数量 |
| `RUNTIME_IMAGE` | `eclipse-temurin:21-jre` | 运行时基础镜像，需提前加载 |
| `JAR_DIR` | `.` | 上传 jar 所在目录 |

## 发布

在 `deploy` 目录指定模块执行（缺省 jar 时自动匹配 `<module>*.jar`）：

```bash
bash start.sh service-admin
bash start.sh service-client service-client-1.0.0-SNAPSHOT.jar
```

脚本执行流程：

1. 校验模块、定位 jar、检查基础镜像是否已加载。
2. 以上传的 jar 在临时上下文中构建应用镜像，例如 `service-admin:prod-20260608120000`。
3. 创建按模块隔离的日志目录。
4. 使用 `deploy/docker-compose.yml` 以 `--no-build` 方式启动容器。
5. 校验容器运行状态，保留最近 `IMAGE_KEEP_COUNT` 个镜像并清理悬空镜像。

## 发布后检查

```bash
docker ps --filter name=service-admin-prod
docker logs -f service-admin-prod
curl -I http://127.0.0.1:18882   # service-admin
curl -I http://127.0.0.1:18881   # service-client
```

## 回滚

```bash
# 查看模块可用历史镜像
docker image ls service-admin --format "{{.Repository}}:{{.Tag}} {{.CreatedSince}}" | grep ":prod-"
# 指定模块与镜像回滚
bash rollback.sh service-admin service-admin:prod-20260608120000
```

## 注意事项

- 回滚只能使用本机仍存在的镜像；默认每个模块只保留最近 3 个生产镜像。
- 回滚只切换应用镜像，不回滚数据库结构和数据。
- 敏感配置不要提交到公开仓库；生产环境慎用 `docker compose down -v`。
