## 在 Grafana 中接入 Prometheus 数据源

Grafana 本身不存储数据，它需要知道去哪里读取数据。你需要将 Prometheus 配置为它的数据源。

1. 登录 Grafana：在浏览器中访问 http://<你的Grafana服务器IP>:3000（默认账号密码通常是 admin / admin123）。

2. 添加数据源：

- 在左侧导航栏点击 Connections（连接） > Data Sources（数据源）。

- 点击 Add data source，在列表中选择 Prometheus。

3. 配置连接：

- 在 URL 处填入你 Prometheus 的访问地址，例如：http://<你的Prometheus服务器IP>:9090。

- 滑到页面底部，点击 Save & test（保存并测试）。如果出现绿色的提示框（Data source is working），说明连接成功！

## 接入 Node Exporter（数据采集器）
在 Prometheus 的 Web 界面（http://IP:9090），点击顶部菜单的 Status > Targets。如果你看到你配置的 node_exporter 状态为 UP，说明数据正在被成功抓取。

数据已经进入 Prometheus 了，最后一步是用 Grafana 把它们漂亮地展示出来。你不需要从头画图表，开源社区有大量现成的模板。

1. 回到 Grafana 界面，点击左侧导航栏的 Dashboards > 右上角的 New > Import（导入）。

2. 在 "Import via grafana.com" 输入框中输入模板 ID：1860 或 8919（这两个是全球最流行的 Node Exporter 监控面板），然后点击 Load。

3. 在底部的 Prometheus 数据源下拉菜单中，选择你在第一步创建的数据源。

4. 点击 Import。

## 接入 cadvisor (容器采集器)
cAdvisor 的 job 状态在 Prometheus 里显示为 UP，说明 Prometheus 已经成功抓取到了 Docker 容器的底层监控指标。

要在 Grafana 中直观地看到这些数据，你不需要自己去一行行写 PromQL 画图，最快且最专业的方法是导入开源社区现成的 cAdvisor / Docker 监控大盘模板。

获取优秀的 cAdvisor 大盘模板 ID
Grafana 社区有很多针对 cAdvisor 的明星模板，以下是两个最推荐的：

- 模板 ID：11600（Docker Containers Dashboard）—— 界面现代化，信息非常全面，支持按容器名称、镜像筛选。

- 模板 ID：14282（Docker Container Monitor）—— 适合同时展示宿主机和容器状态的综合大盘。
