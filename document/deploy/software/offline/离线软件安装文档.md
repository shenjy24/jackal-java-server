# 离线软件安装文档

本文档说明如何在无法访问公网的服务器上安装 Docker Engine、Docker Compose，并创建可执行 Docker 操作的 `tech` 用户。

## 目录结构

将 `document/deploy/software/offline/` 下的文件上传到服务器，例如：

```text
software-offline/
├── install-software.sh
└── pkgs/
    ├── docker-29.5.3.tgz
    ├── docker-compose-linux-x86_64
    ├── iptables_1.8.7-1ubuntu5.2_amd64.deb # 仅目标机缺少 iptables 时需要
    └── （iptables 依赖的其他 .deb 文件）
```

`pkgs` 是推荐目录名，表示离线安装包集合。也可以通过 `PKG_DIR` 指定其他目录。

## 安装

进入离线安装目录：

```bash
cd software-offline
chmod +x install-software.sh
sudo bash install-software.sh
```

脚本会执行：

1. 创建 `tech` 用户，已存在则跳过。
2. 将 `tech` 加入 `sudo`、`wheel` 和 `docker` 组。
3. 检查 `iptables`；Ubuntu 22.04 缺失时，从 `pkgs/` 离线安装主包及其依赖。
4. 解压并安装 Docker Engine，并创建 `containerd.service`、`docker.service`。
5. 安装 Docker Compose 到 Docker CLI 插件目录。
6. 创建后续部署使用的 Docker bridge 网络 `rd_net`，已存在则跳过。

如果安装包名称不同：

```bash
sudo DOCKER_ARCHIVE=docker.tgz \
  DOCKER_COMPOSE_BINARY=docker-compose-linux-x86_64 \
  bash install-software.sh
```

如果需要自定义后续部署使用的 Docker 网络名：

```bash
sudo DOCKER_NETWORK_NAME=rd_net bash install-software.sh
```

如果安装包目录不同：

```bash
sudo PKG_DIR=/data/offline-pkgs bash install-software.sh
```

## Ubuntu 22.04 的 iptables 离线包

适用于 x86_64（`amd64`）Ubuntu 22.04 的版本为 `1.8.7-1ubuntu5.2`。将主包下载并保存为 `pkgs/iptables_1.8.7-1ubuntu5.2_amd64.deb`：

```text
https://security.ubuntu.com/ubuntu/pool/main/i/iptables/iptables_1.8.7-1ubuntu5.2_amd64.deb
```

`iptables` 还依赖 `libip4tc2`、`libip6tc2`、`libxtables12` 等系统库。目标机为精简安装时，请从同一 Ubuntu 22.04 仓库下载缺失依赖的 `.deb`，一并放入 `pkgs/`；脚本会一次执行 `dpkg -i`。安装失败时，`dpkg` 会列出缺失包名，按提示补齐即可。官方包信息和依赖列表见 [Ubuntu Packages](https://packages.ubuntu.com/jammy/iptables)。

ARM64 服务器不能使用上述 amd64 安装包；请下载同版本 `iptables_1.8.7-1ubuntu5.2_arm64.deb` 并通过 `IPTABLES_DEB` 覆盖默认名称。

## 重复执行与回滚

脚本可重复执行：用户、用户组、Docker 网络和 Compose 软链接均会复用；Docker Engine 与 Compose 二进制和离线包一致时会跳过覆盖。

当 Docker Engine 二进制需要更新时，脚本会先停止 `docker`、`containerd`，备份已有的相关二进制到 `/opt/rd300-backups/docker/<时间戳>/`，再通过临时文件替换，避免运行中的 `containerd` 触发 `Text file busy`。停止 Docker 会中断容器，但不会删除镜像、容器或卷数据。

如果新二进制无法启动，可回滚到最近一次自动备份：

```bash
sudo ROLLBACK_DOCKER=1 bash install-software.sh
```

回滚完成后脚本会重新加载并启动 Docker 服务。没有历史备份时不能执行自动回滚。

## 验证

```bash
docker --version
docker compose version
docker network inspect rd_net
systemctl status docker
```

如果 `tech` 用户刚被加入 `docker` 组，需要重新登录该用户后，用户组权限才会生效：

```bash
su - tech
docker ps
```

## 注意事项

- `docker-29.5.3.tgz` 需要是 Docker 官方 Linux 静态二进制包，解压后应包含 `docker/` 目录。
- `docker-compose-linux-x86_64` 需要与服务器 CPU 架构一致。
- iptables 离线安装逻辑仅面向 Ubuntu 22.04，并会校验 `.deb` 架构是否与服务器一致。
- 服务器需具备 `tar`、`cmp`、`readlink`、`groupadd`、`useradd`、`usermod`、`systemctl` 等基础系统命令；缺少 iptables 时还需要 Ubuntu 自带的 `dpkg`、`dpkg-deb`。
